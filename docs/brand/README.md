# Bricriu brand assets

## Selected identity

- [`bricriu-wordmark.svg`](../../public/brand/bricriu-wordmark.svg) and [`bricriu-wordmark.png`](../../public/brand/bricriu-wordmark.png) use the default forms of **Segotia 1.005**, designed by Dominic Stanley and released under the SIL Open Font License 1.1. The SVG contains outlined lettering, not an embedded font. The upstream copyright notice and complete OFL text are retained in [`segotia-OFL-1.1.txt`](../../public/brand/segotia-OFL-1.1.txt).
- [`bricriu-squaremark.png`](../../public/brand/bricriu-squaremark.png) uses the capital `B` from **Gadelica 3**, designed by Séamas Ó Brógáin. It is a static rendering from the unmodified font. The font file and vector glyph outlines are not included in the repository.

Both marks use dark green `#173f34`/`#1f5d49` and warm cream `#fffaf0`. The squaremark is the source for the generated desktop platform icons in `src-tauri/icons/`.

## Earlier comparison

[`bricriu-logo-comparison.png`](bricriu-logo-comparison.png) is a decision sheet, not a finalized logo. It compares each candidate in the two shapes the project actually needs:

- a horizontal `Bricriu` wordmark for the application header and project pages;
- a square `B` mark for application, taskbar, installer, and repository icons.

The sheet contains rendered pixels only. It does not contain or redistribute any font file.

## Candidates and status

- **Bunchló GC 15.00**: downloaded from [Gaelchló](https://www.gaelchlo.com/bungc.html). The default and `ss03` historic `B`/`r` forms are shown. This is not an open-licensed candidate; Gaelchló's published usage terms apply.
- **Gadelica 3** and **Gadelica Gravis**: designed by Séamas Ó Brógáin and downloaded from [Gaelchló's third-party-font page](https://www.gaelchlo.com/clonna2.html). That page says Gadelica may be distributed but not modified. The sheet uses unmodified renderings.
- **Segotia 1.005**: published by Irish Font Club under the [SIL Open Font License 1.1](https://github.com/insert-smiley/Irishfontclub-segotia). The default and `ss01` alternate forms are shown.
- **Cianchló 1.00**: published by Gaelchló under the SIL Open Font License 1.1 and [available from its third-party-font page](https://www.gaelchlo.com/clonna2.html). The default and `ss01` alternate-capital forms are shown.
- **Gaedhilge 0.1 source**: published by Seán de Búrca under the [SIL Open Font License 1.1](https://github.com/leftmostcat/gaedhilge-fonts), but the current repository source contains only lowercase `a` through `d`. It cannot render either requested asset and is shown as unavailable.

The comparison remains as a record of the selection process; it is not an alternative logo set.
